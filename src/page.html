使用与计算说明

已有数据时如何使用

在导入页选择频率或距离，以及 VSWR、正值回波损耗或负值 S11 dB。按模板整理 CSV 后导入。超限点按原值保留；曲线来源显示为“CSV 导入”，本工具不能核验现场接线、仪表校准或数据真伪。同一份导出文件缺少相位信息时，不能由幅度曲线反推出 DTF，软件不会凭空补出另一种模式。

随机仿真的计算模型

按一次进场出图：同批共用型号、序列号、CAL=ON、CW=OFF、采样点数、传播速度和线缆损耗。每条馈线单独抽签主反射位置、中段接头（0–3）和弱反射间距；图内时间按约 2–6 分钟间隔错开。复数 S11 由这些反射的往返相位叠加，并带有很小的底噪；线缆幅度衰减随距离及频率平方根变化。DTF 使用同一复数频率响应，经矩形、Hann 或 Blackman 加窗及逆 FFT 生成。

每条曲线的最大驻波比在限值以内分散，多数落在中段，少数靠近限值。它仍是一阶弱反射模型，不包含完整的多次反射和真实天线谐振。

DTF 分辨率与量程

名义距离分辨率 Δd = c × Vf / (2 × 带宽)，不模糊距离 Dmax = (频率点数 − 1) × Δd。Hann、Blackman 窗可降低旁瓣，同时加宽主瓣。零填充仅让曲线更平滑，不会提高物理分辨率。

判定与导出

VSWR 越小越好；RL 越大越好。换算使用 RL = −20 log₁₀((VSWR−1)/(VSWR+1))。标签仅表示当前曲线与用户设置的门限比较，不代表工程验收结论。Word 保持站点名与内嵌图片的简洁版式，数据来源保留在页面与 Word 文件属性中；图表顶部只保留居中站点名，不再叠加 Distance-to-fault / Return Loss 等测量类型标题；黑色网格、单个 M1 竖线游标和底部三列参数以白底黑字导出，图内不附加“测试数据”字样。未填写型号和序列号时，批次首次生成时自动填入一台常见仪表并整批共用；采样点数、传播速度和线缆损耗使用当前设置，CAL 固定为 ON，CW 固定为 OFF。页面状态和 Word 文件属性仍记录曲线来自随机生成。VSWR、回波损耗和坐标显示两位小数。显示位数不代表实际测量准确度，CSV 原始数值不做舍入。回波损耗采用 0 dB 在上、向下增大至 60 dB 的显示量程，超过量程的读数用界限符号显示。
