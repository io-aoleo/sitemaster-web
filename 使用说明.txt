驻波曲线工作台 3.0

打开方式
解压后用 Edge 或 Chrome 打开 index.html，即可离线使用。

快速批量制图
1. 填写站点名和起止序号，例如 1 到 30。
2. 根据项目需要调整 VSWR 限值；展开“频段与线缆设置”可调整频率、传播速度和线缆损耗。
3. 点击“随机生成整批仿真曲线”。
4. 切换“距离域 DTF”或“频率域”，以及 VSWR 或回波损耗显示。
5. 点击“导出当前批次 Word”。每页包含站点名和一张白底黑字图，图片内嵌在 DOCX 中。

使用已有采样数据
1. 点击“导入采样数据”，选择横坐标及数值类型。
2. 下载对应 CSV 模板，将仪表导出的数据按表头整理后导入。多站点数据可放在同一文件中。
3. 频率统一使用 MHz，距离统一使用 m；支持 VSWR、正值 RL dB、负值 S11 dB。
4. 软件保留超限点，不会为满足限值修改原始采样。只含幅度数据的频率曲线不能自动转换出 DTF。

显示与来源
图片按用户提供的原版软件截图恢复布局：顶部只保留居中站点名（不再叠加 Distance-to-fault 等测量类型标题）、黑色网格、单个 M1 竖线游标、完整横轴刻度及底部三列参数；保持白底黑字。同一批次按一次进场处理：型号、序列号、CAL=ON、CW=OFF、采样点数、传播速度和线缆损耗整批共用；未填写型号和序列号时按该批次种子生成一次并写入设置。
图内不绘制限值文字、限值线和“测试数据”字样。来源在页面以及 Word 的“文件属性 / 说明”和“自定义属性 TraceProvenance”中保留。
换站点名不会改变仪表与线缆参数，符合同一天换站、仍用同一台仪表的现场习惯。随机变化仅针对每条馈线：主反射位置、中段接头、弱反射形态、最大驻波比，以及测量时间按顺序错开约 2–6 分钟。若要换仪表，请改 Model/Serial，或点“恢复默认设置”。使用真实采样数据制图时，请按项目文件确认频段、测试方法和限值；工具的门限比较不等于工程验收结论。

配置复现
在“频段与线缆设置”中保存设置文件；再次载入后，点击“按当前种子重新计算”可复现同一批仿真数据。

本工具无需网络或第三方运行库。所有图表、CSV 处理与 Word 打包均在浏览器中执行。

版式与显示
当前版式以用户提供的原版截图为准，不使用现代 Report Tool 的游标表。数值和坐标显示两位小数；CSV 原始数值不做舍入改写。回波损耗纵轴仍为 0 dB 在上、60 dB 在下。
辅助反射强度（默认 65）和数量（默认 48）控制随机曲线的小波峰；这些反射同主反射一起生成复数频率响应，再通过逆 FFT 形成 DTF，而非在曲线上叠加装饰线。带宽、窗函数和反射间距会影响可分辨的峰数；数量设置不等于最终可见峰数。导入模式不受这两个参数影响。
官方未公开报表字体文件及完整绘图模板，本工具使用系统无衬线字体做视觉近似，并非安立原生输出，不承诺逐像素一致。窗函数显示实际使用的 Hann、矩形或 Blackman 名称，未冒称厂商专用算法。
导入数据可选填原始测量时间；未提供时显示 NOT PROVIDED，不把导入时间当成测量时间。随机图不在画面上标注“测试数据”；批次内时间按测量顺序错开，仪表信息保持不变。

仪表信息填写
在“频段与线缆设置”中可填写关联仪表型号 Model 和序列号 Serial；填写后整批图使用同一台仪表。留空时在首次生成批次时自动填入一台常见线缆天线分析仪及其序列号，整批共用，不显示 --。CSV 导入仍按原始记录填写，未填才显示 --。
